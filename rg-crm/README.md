# РГ CRM — аналитика агентов

Отдельный статический сайт на VPS (не WordPress, не arrj.ru).

## URL

**http://159.194.229.87/crm/**

## Локальный запуск

```bash
cd rg-crm
python3 -m http.server 8765
```

Открой: http://127.0.0.1:8765/

## Деплой на VPS

```bash
./scripts/vps.sh crm-push
```

Данные: `data/metrics.json` (генерируется из Excel в `source/`).

## Мобильная версия

На экранах ≤900px: фиксированный верхний бар, выдвижное меню, нижняя навигация, горизонтальные чипы периода, поиск агентов.
